**nip.io** 是一个免费的通配符 DNS 解析服务，它允许开发者通过在域名中直接嵌入 IP 地址，自动将该域名解析到对应的 IP。它在软件开发、容器化部署和本地调试中非常受欢迎。

## 核心功能与用法

- **免配 hosts**：无需修改本地的 hosts 文件，即可使用直观的域名来访问特定的 IP。 [[1](https://cloud.tencent.com/developer/article/1867494)]
- **使用格式**：只需将目标 IP 拼接在 `nip.io` 前面。
    - `127.0.0.1.nip.io` -> 解析到 `127.0.0.1` (本地)
    - `192.168.1.100.nip.io` -> 解析到 `192.168.1.100`
    - 支持将连字符形式的 IP（如 `192-168-1-100.nip.io`）解析到对应的 IP。 [[1](https://www.cnblogs.com/shanyou/p/15173337.html), [2](https://nip.io/)]

### **主要应用场景**

- **本地开发调试**：在前端或微服务开发中，当某些接口或 OAuth 认证要求必须使用 HTTPS 域名而不是 IP 时，使用 nip.io 可以非常方便地生成可用的测试域名。
